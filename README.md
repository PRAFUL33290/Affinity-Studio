# Affinity Studio

Site statique autour d'Affinity avec plusieurs pages HTML publiees sur GitHub.

## Pages

- `index.html` : guide principal Affinity Essentials 2026
- `comparatif.html` : comparaison Affinity, Adobe et Canva
- `canva.html` : analyse de Canva et de son integration d'Affinity
- `ipad.html` : focus sur l'experience iPad

## Fichiers associes

- `comparatif.md`
- `RACCOURCI AFFINITY.pdf`
- logos et images utilises par les pages
